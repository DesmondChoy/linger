# What the grades establish

The scenario and component scores measure different behaviors. Keep their recorded grades and use the underlying observations to prioritize corrections. No expectation or production behavior was changed during this investigation.

## Why the component pass does not contradict unsafe scenario behavior

The 12-case release suite constructs an explicit completed-chapter introduction for every Alice question. The notebook helpers also bind a confirmed chapter scope. These cases exercise retrieval and evidence selection within known permission; they do not test whether the model can infer permission from an ambiguous event. The cross-source smoke similarly supplies “finished Chapter 5.” A passing result on these cases cannot clear the unsafe Douglass, Keller, or Pinocchio boundary decisions. See [release introduction](/Users/kevinmanuel/Documents/REPO/linger/evals/librarian/live_validation.py:117) and [smoke input](/Users/kevinmanuel/Documents/REPO/linger/evals/serendipity/objective_cases/cross-source-outside-essay-v1.json:6).

The release aggregate permits some case-level loss: recall and strength are averaged across all cases, and its release-rate assertion checks the release source. It does not independently judge every semantic detail of the final answer. `pigeon-serpent` retained only one of two gold ranges after a Provenance revision while the suite still met its targets. Because the saved release artifact intentionally excludes replies, completeness cannot be reconstructed from that artifact. See [aggregation](/Users/kevinmanuel/Documents/REPO/linger/evals/librarian/live_validation.py:375) and [case analysis](standalone/analysis.md).

## Confirmed evaluator mechanics

1. **Boundary support is treated as a closed set.** `_evidence_sets_match` requires every authored support span to be represented and every actual support record to belong to an authored accepted record set. A direct local execution showed that required support alone passes, while the same support plus an unlisted record fails. The probe does not establish that arbitrary extras are valid; the corpus reviews establish that the particular extras in Alice, Douglass, and Farm are valid. Preserve the exact-scope and required-support checks, but review whether the authored support list is intended to be exhaustive. Do not simply allow every extra record. [Matching code](/Users/kevinmanuel/Documents/REPO/linger/evals/synthetic_journals/book_replay.py:1035), [probe](grading-investigation-probes.json), [scenario reviews](evaluation-report.md).

2. **A spoiler-only grade does not verify a requested quotation.** The inferred-boundary branch checks the selected ceiling, support, and upper limits on retrieval. It does not require the retrieval ceiling to equal the allowed maximum or require any book evidence to be returned. Keller therefore passes its spoiler grade despite Muse excluding Chapter 10 and declining the requested quotation. The same issue is caught in Pigeon because that Scene also has a grounded objective. Add separately adopted quotation/completeness coverage where the Scene's intent includes it; do not alter the current grade. [Spoiler branch](/Users/kevinmanuel/Documents/REPO/linger/evals/synthetic_journals/book_replay.py:963), [quotation checks in grounded branch](/Users/kevinmanuel/Documents/REPO/linger/evals/synthetic_journals/book_replay.py:928).

3. **Farm's handoff label conflates invalid output with a content leak.** `_boundary_handoff_is_content_free` returns false when the recorded boundary output is not a dictionary. Farm's failed exchange has no valid output, so that condition fails even though the application emits a content-free clarification and grants nothing. Retain an execution failure, but distinguish “no valid model output” from “story content crossed the boundary.” [Handoff predicate](/Users/kevinmanuel/Documents/REPO/linger/evals/synthetic_journals/book_replay.py:698).

4. **The notebook compares canonical text with raw source whitespace.** The benchmark scorer requires exact string equality with a source line slice. The canonical paragraph resolver joins paragraphs with two newlines. One `drink-me` result differs only by one blank line, while its canonical citation ID resolves correctly. This is a mismatch between two text contracts. Verify IDs, version hashes, locations, and text through the canonical resolver; retain a separate raw-source integrity check with an explicit normalization policy. [Raw comparison](/Users/kevinmanuel/Documents/REPO/linger/evals/librarian/benchmark.py:301), [canonical assembly](/Users/kevinmanuel/Documents/REPO/linger/apps/backend/librarian.py:143), [exact diagnostic](standalone/direct-citation-diagnostic.json).

5. **The theme gold needs an intent decision.** `identity-theme` expects weak support and two episode ranges, but asks how changing size and uncertain identity reinforce each other. The selected Chapter 5 text directly connects the two. The current evidence-selection policy asks for the shortest useful supported answer, not all illustrations. This supports a potential stale-gold diagnosis, not automatic relabeling. Decide whether the intended requirement is a two-episode synthesis or the existing bounded question. [Frozen case](/Users/kevinmanuel/Documents/REPO/linger/evals/librarian/cases.json:13), [selection policy](/Users/kevinmanuel/Documents/REPO/linger/src/linger/agents/librarian/skills/evidence-assessment/SKILL.md:52).

6. **The cross-source stage report is a dependency cascade.** Its grader marks all later stages `not_reached` after the first failed check, irrespective of later observed events. Interpret that as an unmet grading dependency, not proof that subsequent agents never ran. Use the saved transcript/events for the actual execution path. [Stage loop](/Users/kevinmanuel/Documents/REPO/linger/evals/serendipity/objective_replay.py:128).

## What this says about decomposition and false negatives

The production path retains the original request and prior reader statements alongside focused exact-span queries. It searches each, interleaves their candidates, and asks the assessor to compare the plan against the original request. The current private hybrid path preserves the fusion leader and ranked candidates even below the public retrieval cutoff; it does not discard every score below 0.5 before assessment. This is why the old retrieval-only benchmark and the live agent can disagree. The benchmark still thresholds reranker scores and its “strength” metric is a gold-coverage proxy, not a model judgment. [Query fallback and merge](/Users/kevinmanuel/Documents/REPO/linger/src/linger/orchestration/book_evidence.py:96), [private retrieval](/Users/kevinmanuel/Documents/REPO/linger/apps/backend/hybrid_librarian.py:274), [benchmark scoring](/Users/kevinmanuel/Documents/REPO/linger/evals/librarian/benchmark.py:306).

These safeguards reduce omission risk; they do not eliminate it. Each search returns at most five private candidates, the book pool is capped at twenty, and added needs discovered during assessment do not trigger another retrieval pass. An assessor can report weak support for a recovered need, but cannot find a passage absent from the pool. The separate cached-hybrid investigation reproduced Keller's eight-record private boundary pool exactly: its canary alternative reaches fusion rank four for the memory query, then drops out of the per-query top-five selection after reranking. This establishes a candidate-retention failure, rather than a decomposition omission or an overall pool-cap failure. See [scenario diagnosis](investigation-scenarios.md). It does not justify suppressing uncertain queries. [Budgets](/Users/kevinmanuel/Documents/REPO/linger/src/linger/orchestration/book_evidence.py:27), [assessment-only additional parts](/Users/kevinmanuel/Documents/REPO/linger/src/linger/orchestration/evidence_strength.py:107).
