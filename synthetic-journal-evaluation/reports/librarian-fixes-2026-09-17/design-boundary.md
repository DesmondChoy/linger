# Boundary authorization design

Keep the reusable Librarian Agent and its existing boundary skill. Search remains broad and private. A chapter grant must follow an explicit comparison of possible current event occurrences against the original reader wording; a vaguely repeated memory is not a distinguishing detail.

`BoundaryInferenceDecision` becomes candidate-only. It requires `event_resolution`: exact `reader_event_spans`, grouped `occurrences` (canonical evidence IDs, selected or ruled out, exact distinguishing reader spans, explanation), and `other_evidence_ids`. Exactly one occurrence is selected. Every private candidate must be accounted for once, whether as an event occurrence or other evidence. The selected occurrence must be included in boundary support and establish the declared current ceiling. All reader spans must be exact original current/prior reader text; model-written paraphrases and memory-only identification cannot satisfy them. Alternative occurrences cannot be ruled out without an actual distinguishing reader detail. A compound, specific reading sequence can be one identified stopping sequence; earlier memory need not be in the stopping chapter.

`BoundaryUncertainDecision` is a separate output model with memory assessments, confidence, and reason code. It exposes no work/chapter/authorization/support grant fields. `PassageInferenceDecision` remains unchanged. The output union contains these three explicit outcomes; internal callers are migrated rather than retaining the obsolete mixed constructor.

The existing Agent capability validates memory coverage and exact occurrence proof against the full original input, retrying within the existing budget. The application repeats those checks before granting scope, including injected decisions. Typed proof improves omission detection and auditability but does not make semantic truth deterministic; the skill explicitly treats missing animal/speaker/setting/cause as unresolved when those details distinguish plausible occurrences, even if retrieval returned only one. Broad retrieval is preserved; confidence and relevance scores never replace identification.

Tests first reject a high-confidence grant without reader-identification proof, require a separate uncertainty tool with no grant schema, reject omitted competing records and invented distinguishing spans, and preserve coherent compound stops with earlier memory. Existing boundary fixtures migrate to explicit proof. Root owns replay parsing and evaluation fixture migration. No provider calls in this implementation subtask.
