# Repair 15: Provenance copy feedback and semantic distinctions

Iteration14 smoke repaired its public source mapping, then lost release because three reviewer outputs copied private source pronouns incorrectly. The validator correctly rejected all three. Pigeon also exposed an overstrict category-quote classification, while Roses showed both a defensible reflective framing rejected as a research claim and an actual individual-cause conclusion accepted too readily.

Keep the existing input/output schemas, positive literal-proof requirement, source identities, complete audits, review stage and retry limits. No model change, source substitution, normalization expansion, or automatic support assignment.

For an invalid private source excerpt, add a small diagnostic context from the same named canonical source. Standard-library token-sequence matching locates a substantial unique shared span; original source character offsets recover an exact local context. Limit matching input size and omit hints for missing, too large, unrelated or ambiguous text. This context is a copy aid, not a suggested semantic conclusion or auto-filled excerpt. The submitted review still fails until its own excerpt satisfies the unchanged canonical validator. Test the captured smoke failure pattern with changed pronouns and a real FunctionModel repair; test wrong-source borrowing and ambiguous/no-source cases remain rejected or receive no hint.

Replace the existing quotation classification instructions with a contextual distinction: naming a category with scare quotes does not claim to reproduce a speaker's exact words, whereas attributed speech, modified quotations and poetry lines do. Source vocabulary alone does not decide classification. The model continues to classify all spans; no keyword exception or deterministic semantic approval is added.

Replace overlapping reflective-policy prose with a clear division between (1) mapped factual findings and comparisons, (2) nonfactual framing that offers an already established source as a lens without adding a source proposition, and (3) a claim that the source warrants a cause for this individual. A qualified exploration may be a possibility, with alternatives and permission to reject it. A "careful conclusion" that fear contributed still asserts a cause; statistical associations and later rationalizations cannot establish that cause. Preserve complete declaration coverage for substantive book/web/memory claims, timing and source-local entailment.

Offline regressions establish literal feedback and unchanged authority; they cannot prove that the model reliably applies these semantic distinctions. Existing quotation, grouping, and reader-reflection tests remain required, with live efficacy reserved for the separately authorized next evaluation set.
