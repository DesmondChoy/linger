01 · Product journey

What works today

Status is judged against the four stages in the canonical specification. “Working” means the current narrow slice is exercised; “partial” means important target behavior is still deliberately absent.

Reflect

Every Line receives a request-local emotional preflight; Muse then produces one typed candidate whose specialist evidence survives through isolated Provenance review and deterministic release.

Instrumented slice

Still needed: photograph input and complete authority declarations for image, web, and private-memory claims.

Ground

Alice retrieval supports direct, BM25, semantic, hybrid, and reranked strategies with exact citation validation.

Alice-first slice

Private inference validates memory-backed chapter ceilings or exact session-supported paragraphs before evidence retrieval. Shared Scene facts govern book replay. Other prepared corpora need deliberate runtime registration and evaluation; approved operating budgets remain open.

Preserve

Controlled automatic capture binds exact user text to independent review, suppresses application-authored responses, commits through deterministic policy, and replays across 11 synthetic Scenes.

Evaluation slice

Blank nominations fail before storage. Server-owned durable event identity remains open. Public memory management and the versioned schema remain deferred.

Reconnect

Serendipity can search the active account memory view, a confirmed Alice scope, or policy-enabled Exa. It ranks a tentative connection and exposes a privacy-safe hand-off in Inspect. Only selected book evidence has public release authority.

Book-only release path

Still needed: citation authority for web, memory, and photograph evidence.

03 · Evaluation programme

Evaluate each authority boundary.

The canonical catalog defines eleven Objectives. Strict Backstory, Prop, Scene, Line, and proposed Ground truth contracts preserve the separation between runtime inputs and evaluator-only judgments.

Synthetic journal evaluation

Objective-specific contracts and replay.

Capture replay checks nomination, exact spans, independent review, binding, storage outcomes, and record counts. Continuity replay keeps related Lines in one session. Book replay compiles shared Scene facts and Objective-owned expectations into one validated plan. Bounded curation replay examines Sculptor proposals and source preservation.

The surfacing runner evaluates a supplied memory batch and a typed decision. It does not retrieve, deliver, schedule, or run the planned conversational capture-to-curation demonstration.

05 · Product boundaries

Separate working behavior from target scope.

Internal discovery, deterministic storage, and a passing synthetic decision each establish a different capability. Public release and an end-to-end conversational demonstration require their own contracts and evidence.

Available

Review and preserve

Typed reflection, chapter and exact-passage grounding, session-line reuse, reviewed automatic capture, and internal reviewed curation preserve application-owned authority.

Internal only

Discover with bounded sources

Serendipity can inspect account memories and optional public-web sources. Memory and web proposals fail closed at public release until citation authority is implemented.

Target

Demonstrate conversational surfacing

The target joins conversation-created memories, independent curation review, deterministic storage, later retrieval, and a reviewed surfacing response. The supplied-batch surfacing runner does not establish that loop.
