03 · Evaluation programme

Evaluation is its own delivery stream.

The project has five complementary proof layers: deterministic suites, fixed role packs, a provider-backed Librarian slice, manual end-to-end routes, and a scenario-first synthetic programme. The synthetic slice includes strict package contracts, validation, independent Ground truth review, capture and curation replay, durable transcripts, native evaluation cases, agent hand-off spans, and Logfire trace correlation.

Synthetic journal evaluation

10 Objectives. Three packages. Two replay workflows.

The catalog covers conversation and memory, retrieval and grounding, and safety and security. One 11-Scene capture package and two five-Scene bounded-curation packages use strict Backstory and proposed Ground truth contracts. Capture replay exercises production Muse, Provenance, and Memory & Policy; curation replay exercises production Sculptor with immutable source hashes and dual evaluation identities. Both publish native cases to the isolated linger-evals Logfire service without exposing Backstory or Ground truth to Linger.
