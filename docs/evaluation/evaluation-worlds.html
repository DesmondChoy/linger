Workflow boundary

Confirmation produces a human-only planning report.

Report, then stop

Inspect the current repository before generating data

The repository’s generate-synthetic-journals skill selects objectives, confirms them, then writes a timestamped one-page Markdown report for human review.

  • The report snapshots the implementation, proposes the generator prompt, and summarizes Line, evaluation, architecture, and academic implications.
  • It decides whether the proposed Backstory is corpus-backed or memory-only; book-backed prompts point to the current data/corpus/ directory instead of hardcoding a work.
  • For spoiler tests, Librarian searches the complete work to infer a ceiling, but only bounded evidence may reach Muse.
  • The report is for the developer only and is never passed to a generator.
  • Confirmation creates no backstories, props, scenes, lines, ground truth, annotations, packages, review records, frozen releases, or replay data.
  • No downstream workflow defaults are defined.
Linger system specification, section 7.2, Scenario-first synthetic journal evaluation · the downstream workflow is intentionally undefined.
