Five-minute executive brief

Five evaluation worlds for Linger’s 40-case baseline.

Use five user histories and 40 fixed cases to test Linger’s product usefulness, compare its agent architecture with a single-agent system, and measure the cost of specialisation.

Decision requested

Approve the five evaluation worlds and Maya pilot. The worlds keep case histories coherent; the frozen cases test product usefulness and the agent architecture. Market demand requires separate user research.

01 / The goal

Help people think with what they have read and remembered.

Linger helps readers reflect while keeping their voice, sources, and boundaries intact.

Carry meaning from a book or moment into a person’s life, then help them find it again with its source, context, and boundaries intact.
Reflect

Keep the person’s voice

Ask useful questions and keep the meaning in the reader’s own words.

Ground

Use evidence selectively

Retrieve from books, memories, or the web when the response needs support.

Preserve

Save meaning with consent

Keep durable insights inspectable, scoped, and reversible.

Reconnect

Keep changes visible over time

Recover earlier thinking and offer grounded connections across time.

Rules that apply everywhere

The same trust rules apply across Reflect, Ground, Preserve, and Reconnect: spoiler boundaries, consent, account scope, deletion, provenance, and safe release.

Evaluation plan

The 40 cases test the claims within five coherent user histories.

01 / Fixed cases

Use the §7.2 acceptance criteria

The specification defines the case counts and required outcomes.

  • 15 safety or adversarial overlays
  • 5 reflection and 5 memory-capture cases
  • 10 expected-connection cases
  • 5 weak-evidence cases
  • Retrieval strategy and Sculptor curation remain in §7.1
Fixed evaluation set · new cases based on failures extend the set while preserving every baseline case.
02 / Architecture comparison

Hold inputs steady and vary the architecture

Use the same base model, fixed case inputs, available evidence, and application rules for:

  • single-agent system;
  • full five-role agent system;
  • adaptive Librarian compared with the strongest fixed retrieval;
  • separate Provenance review compared with review inside Muse; and
  • connection cases with and without Serendipity.
Run every applicable fixed case on every version. Every version must pass all safety checks. A useful result improves evidence outcomes or reduces unsupported claims. Report latency, tokens, and cost. Keep outputs from reduced systems inside the evaluator.
03 / Pilot to freeze

Use synthetic tools for drafts and reviewers for decisions

Start with 6–8 Maya cases: reflection that skips retrieval, grounded retrieval, allowed and vetoed capture, explicit save, weak-evidence decline, reconnection, and one safety overlay.

  • Two reviewers independently check routes, evidence, forbidden outputs, and expected labels.
  • Reviewers resolve disagreements before freezing a case.
  • Use behaviour coverage to decide how many cases each world needs.
  • Publish each version with a dataset card and limitations.
Synthetic tools can draft histories and dialogue. Reviewers set expected behaviour and expected labels.
