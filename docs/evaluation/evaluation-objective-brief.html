How it works

Human approval gates planning, generation, adoption, and replay.

Plan, approve, review, replay

Keep every authority transition explicit

The repository separates Objective confirmation, report approval, synthetic-data generation, independent Ground truth adoption, and provider-backed replay.

  1. Configure Logfire. Configure the Linger project before a provider-backed evaluation so an accepted replay can publish Pydantic Evals results and synthetic-only traces.
  2. Select Objectives. Run the generate-synthetic-journals skill. Its local selector groups all ten Objectives by the catalog's menu families and accepts one through ten. The explorer on this page is not that selector.
  3. Review the plan. Selection confirmation creates only a timestamped pre-generation-report.md. Read it, then separately approve its design and detached generator prompt, request changes, or abandon the attempt.
  4. Generate and validate. Only separate approval authorizes a generator to add sibling backstory.json and ground-truth.json. Deterministic validation checks objective facts. The report stays human-only and never reaches the generator wholesale or the system under evaluation.
  5. Review Ground truth. Run the review-synthetic-ground-truth skill. A human independent of the generator approves or flags every proposed Ground truth row.
  6. Adopt or revise. Make Changes writes no adoption and invokes no runtime. Confirmation writes ground-truth-adoption.json; the agent starts one replay only for a supported single Objective. Automatic post-confirmation routes currently cover reviewed automatic capture and bounded memory curation.
  7. Inspect the replay. Review the experiment in Pydantic Evals and Logfire, and retain the runner's JSON output as the durable evaluation record.
Linger system specification, section 7.2, Scenario-first synthetic journal evaluation · the repository defines the package-directory layout, Backstory and Ground truth structures, deterministic validator, desktop review and adoption workflow, and automatic capture and bounded-curation replay routes. Reusable generation, full-dataset layout, freezing, and automatic replay for other Objectives remain undefined.
