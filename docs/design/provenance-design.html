Reasoning role · Design & progress

Provenance

The independent release gate reviews one complete Muse candidate as untrusted data. It decides whether the response may ship and, separately, whether a proposed memory may be captured—without tools, conversation history, or storage authority.

Pr
Independent release gateMandatory gate
01 · Responsibility

Review the candidate, never trust it.

Provenance is isolated so Muse cannot approve its own wording, evidence claims, spoiler scope, or automatic memory nomination.

May decide

Pass, revise, or reject a response; identify exact risky spans with typed findings; allow, reject, or record no automatic memory candidate; and give one focused critique for revision.

May not decide

What Muse should say initially, which evidence to retrieve, who the account is, what storage policy permits, or whether a rejected draft may be shown. It has no tools and no memory access.

02 · Implemented flow

Two verdicts from one isolated review.

The application assembles the entire authorised review bundle. Missing evidence or unclear boundaries fail closed rather than being inferred.

Choose release verdict

Pass as written, request one focused revision, or reject when correction is unsafe or insufficient.

04 · Capture path

Choose capture verdict

Evaluate the exact user-text nomination independently from response quality.

capture_decision: allow_capture | reject_capture | no_candidate
05 · Application

Run deterministic checks

Resolve evidence, exact quotes, scope, and reviewed nomination before any release or capture hand-off.

validated release | bounded retry | safe decline
06 · Release

Suppress unsafe drafts

Only a passing candidate is displayed; rejection produces application-authored safe text.

never leak rejected candidate text
